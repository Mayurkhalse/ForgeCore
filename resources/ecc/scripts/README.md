# ECC Passive Reference Scripts Policy

> **Security Mandate:** ZERO RUNTIME EXECUTION AUTHORIZATION (ADR-009)

Scripts located in this directory are bundled strictly as read-only static text
and code documentation assets. Sarthi runtime, MCP servers, and verification runners
are strictly forbidden from executing these scripts.

### Included Reference Assets:
- `evaluate.py`: Standalone 5-axis agent evaluation rubric reference script.
